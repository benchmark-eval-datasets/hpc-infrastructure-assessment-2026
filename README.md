# HPC Infrastructure Assessment Dataset

A comprehensive dataset for evaluating high-performance computing (HPC) infrastructure procurement, migration planning, budget reconciliation, and executive briefing workflows.

## Contents

This repository contains 27 data files across 3 formats representing a university HPC center's operational records:

| Format | Count | Description |
|--------|-------|-------------|
| CSV    | 13    | Telemetry, job accounting, inventory, configuration, and survey data |
| PDF    | 11    | Vendor quotes, technical datasheets, facility assessments, policies, and agreements |
| XLSX   | 3     | License manifests, grant portfolios, and maintenance logs |

### File Listing

#### CSV Files
- `departmental_usage_survey_fy2026.csv` — Department-level usage survey responses
- `departmental_usage_telemetry.csv` — Automated departmental resource consumption metrics
- `gpu_utilization_telemetry_fy2026.csv` — GPU hardware utilization time-series data
- `hpc_detailed_financial_records.csv` — Line-item financial transaction records
- `hpc_hardware_inventory_2026.csv` — Current hardware asset inventory
- `hpc_job_accounting_monthly_summary.csv` — Scheduler job accounting aggregates
- `hpc_operations_budget_fy2027.csv` — Proposed FY2027 operating budget
- `hpc_power_telemetry_week.csv` — Data center power draw time-series
- `hpc_support_tickets_fy2026.csv` — Help desk ticket records
- `lustre_ost_performance_daily.csv` — Parallel filesystem performance counters
- `network_performance_counters.csv` — Network fabric telemetry
- `slurm_scheduler_config_extract.csv` — Scheduler configuration parameters
- `whpc_environmental_monitoring_logs.csv` — Environmental sensor readings

#### PDF Files
- `facilities_power_cooling_assessment.pdf` — Data center facilities engineering assessment
- `hpc_center_org_chart_staffing.pdf` — Organizational chart and staffing plan
- `hpc_governance_policy_v3.pdf` — Resource allocation and governance policy
- `network_topology_hpc_cluster.pdf` — Network architecture documentation
- `nexagen_x9000_technical_datasheet.pdf` — Vendor hardware technical datasheet
- `storage_vendor_quote_ultrastore.pdf` — Storage system vendor proposal
- `vendor_benchmark_validation_report.pdf` — Independent benchmark validation report
- `vendor_quote_nexagen_hpc.pdf` — Compute cluster vendor proposal
- `vendor_service_agreement_nexagen.pdf` — Vendor service level agreement
- `whpc_storage_io_performance_and_tuning_assessment.pdf` — Storage I/O tuning assessment
- `whpc_workload_analysis_and_scheduling_framework_fy2026.pdf` — Workload analysis framework

#### XLSX Files
- `departmental_research_grant_portfolio.xlsx` — Research grant and funding portfolio
- `hpc_hardware_maintenance_log.xlsx` — Hardware maintenance event log
- `software_license_manifest.xlsx` — Software license inventory and allocation
